## Milestone Summary

**Decimal Phases:**

- Phase 14.1: 与上游最新源码完全对齐并保护现有多语言进度（因用户要求在继续 Claude zh-CN 落地前先与 upstream 最新代码面对齐而插入）

**Key Decisions:**

- 先关闭 v1.1 残余测试债务，再继续扩展新的 Claude installer/localization 表面，避免把旧失败拖入新 contract
- Claude display metadata 继续沿用 English canonical source + locale-specific display layer 的边界，只本地化 `description` / `short-description`
- Claude locale fallback 采用 pair-level fallback，任一字段缺失即整对回退 English canonical，禁止 mixed-language frontmatter
- 真实 upstream sync 采用 clean-base integration worktree + replay 本地 WIP 的双阶段模式，避免在脏主工作树直接 merge
- Claude first-batch zh-CN 承诺面与 wider inventory English baseline 必须分层：前者 blocker，后者 boundary regression

**Issues Resolved:**

- `bug-1736` / `bug-2248`：Windows 本地安装回归测试 teardown 的 EPERM 清理失败
- `bug-1754`：aggregate hook guard regex 与 installer warning 源码漂移
- `kilo-install`：Kilo help text 与上游同步后字面量不一致
- Claude skills 在 installer 侧缺乏独立 locale catalog、pair-level fallback 和真实 install-output regression coverage
- Claude first-batch display / install surfaces 未接入治理 blocker，无法作为正式本地化承诺面验收
- sync 前本地代码面落后于 `upstream/main`，无法在最新源码上重做 Phase 15

**Issues Deferred:**

- Claude wider inventory 的 `zh-CN` display copy 扩容
- 其他 skill-based runtime 的 display-layer locale contract 扩展
- `ja-JP` / `ko-KR` / `pt-BR` 对 Claude skills 的更高质量本地化补齐

**Technical Debt Incurred:**

- 无。`v1.2` milestone audit 为 `passed`，Nyquist 为 `compliant`，`audit-open` 结果为 clear。
