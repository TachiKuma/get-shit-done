### Claude Skills Locale Catalog 架构

- [x] **CLD-01**: 用户安装 GSD 后，首批 Claude skills 在 zh-CN locale 下显示中文 description 与 short-description（来自 `get-shit-done/locales/zh-CN/claude-skills.json` catalog）
  - **Outcome:** Phase 14 — 建立 `claude-skills` English baseline 与首批 6-skill `zh-CN` skeleton，真实安装产物回归测试确认中文 frontmatter 生效
- [x] **CLD-02**: `bin/install.js` 支持 Claude skills locale-aware display metadata 解析，zh-CN 缺失时整对 fallback 到 English canonical，不产生中英混合 frontmatter
  - **Outcome:** Phase 14 — `resolveClaudeSkillDisplayMetadata()` 与 shared converter seam 落地，seam-level 与 output-level 测试都锁定 pair-level fallback
- [x] **CLD-03**: Claude skills locale catalog 接入 governance verifier，首批 zh-CN 承诺面失败时 verifier 返回非零退出码（对标 QA-04 / Codex blocker 模式）
  - **Outcome:** Phase 15 — governance manifest 新增 Claude first-batch display/install blocker groups，coverage test 与 verifier output 基线同步升级

### Claude Skills Display Copy

- [x] **CLD-04**: 首批重要 Claude skills 的 zh-CN display copy 落地（description + short-description，覆盖最常用的若干 GSD skills，体量类似 Codex 首批 6 个）
  - **Outcome:** Phase 15 — 正式锁定首批 6 个 Claude skills 的 `zh-CN` promised subset，并通过独立 blocker-scoped display localization test 验收
- [x] **CLD-05**: locale 整对 fallback 机制有测试锁定，不出现中英混合 frontmatter（English description + 中文 short-description 等混合情形）
  - **Outcome:** Phase 14 — catalog contract、installer seam 与真实 install output 三层测试共同守护 pair-level fallback，不允许 mixed-language frontmatter

### Quality

- [x] **QA-05**: Claude skills install output 在 `en` 与 `zh-CN` 两种场景下的关键文案生成有自动化回归测试覆盖，installer 回退到英文-only 时测试失败
  - **Outcome:** Phase 15 — first-batch install-output blocker suite 与 non-blocker remainder fallback-boundary suite 同时落地，`en + zh-CN` 安装表面具备完整门控
